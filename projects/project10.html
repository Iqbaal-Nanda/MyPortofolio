About This Project


Aplikasi E-Commerce Checkout Flow adalah sistem berbasis web yang dirancang untuk menggantikan proses keranjang belanja dan checkout manual.
Proyek ini dikembangkan menggunakan teknologi HTML5 CSS3 & JavaScript.
Tujuan utama sistem ini adalah memberikan kemudahan bagi user dalam mengelola keranjang belanja dan checkout.
Checkout flow adalah proses transaksi dalam sistem e-commerce yang dimulai dari pemilihan produk hingga pembayaran.

Main Features


  • Checkout Flow:
    Checkout Flow menampilkan ringkasan data keranjang belanja dan checkout.
  • Shopping Cart:
    Shopping Cart menampilkan ringkasan data keranjang belanja dan checkout.
  • Payment Gateway Integration:
    Payment Gateway Integration menampilkan ringkasan data keranjang belanja dan checkout.

About This Project


Aplikasi Sistem Pelaporan Statistik Badan Penanggulangan Bencana Daerah (BPBD) ini dirancang sebagai sistem komprehensif untuk mengelola dan memvisualisasikan data kebencanaan.
Proyek ini dikembangkan dengan fokus utama pada visualisasi data (Data Visualization) dan penyajian data secara real-time menggunakan library charting canggih dan komponen UI modern.
Tujuan utama sistem ini adalah memberikan kemudahan, kecepatan, dan akurasi data bagi pihak BPBD dalam mengambil keputusan.

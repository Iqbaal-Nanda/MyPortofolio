About This Project


Aplikasi monitoring perangkat jaringan sederhana berbasis web yang dirancang untuk menggantikan proses monitoring perangkat jaringan manual.
Monitoring perangkat jaringan adalah kegiatan memantau kondisi perangkat jaringan untuk memastikan perangkat berjalan dengan baik dan optimal.
Proyek ini dikembangkan menggunakan teknologi HTML5 CSS3 & JavaScript.
Tujuan utama sistem ini adalah memberikan kemudahan bagi admin dalam memonitoring perangkat jaringan.
Perangkat jaringan meliputi:
- Router
- Switch
- Access Point
- Firewall
- Server
- Client

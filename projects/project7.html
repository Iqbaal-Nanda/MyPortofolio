Sistem inventaris & manajemen barang

Inventory Management System HTML5 CSS3 & JavaScript

About This Project


Aplikasi Inventory Management System adalah sistem berbasis web yang dirancang untuk menggantikan proses manajemen inventaris manual.
Proyek ini dikembangkan menggunakan teknologi HTML5 CSS3 & JavaScript.
Tujuan utama sistem ini adalah memberikan kemudahan, kecepatan, dan akurasi data bagi pihak admin maupun user.

Main Features


  • Dashboard:
    Dashboard menampilkan ringkasan data inventaris secara real-time.
  • Item Management:
    Admin dapat mengelola data barang (tambah, edit, hapus).
  • Supplier Management:
    Admin dapat mengelola data supplier (tambah, edit, hapus).
  • Purchase Management:
    Admin dapat mengelola data pembelian (tambah, edit, hapus).
  • Sale Management:
    Admin dapat mengelola data penjualan (tambah, edit, hapus).
  • Report Management:
    Admin dapat membuat laporan inventaris.
  • User Management:
    Admin dapat mengelola data user (tambah, edit, hapus).

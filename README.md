# MyPorto

Portofolio pribadi statis untuk Iqbaal Nanda, menampilkan proyek, kontak, dan visual interaktif.

## Fitur

- Halaman portofolio HTML/CSS/JS sederhana
- Background video dan animasi Three.js
- Navigasi berbasis sections dengan efek magnetik dan tilt
- Player musik latar
- Form kontak yang membuka email client atau Gmail compose
- Overlay project untuk menjaga audio/video tetap berjalan saat membuka project
- Efek hover dan transisi modern

## Struktur File

- `index.html` - halaman utama portofolio
- `styles.css` - styling utama
- `script.js` - interaksi dan logika JavaScript
- `assets/` - folder aset: gambar, video, musik
- `projects/` - halaman detail proyek

## Cara Menggunakan

1. Buka `index.html` di browser.
2. Klik menu navigasi untuk pindah ke bagian yang diinginkan.
3. Scroll untuk melihat proyek, pengalaman, dan kontak.
4. Isi form kontak lalu klik `Send Message` untuk membuka email client.

## Catatan

- Form kontak saat ini mengandalkan `mailto:` untuk membuka aplikasi email default atau Gmail compose.
- Untuk pengiriman email otomatis tanpa membuka klien, dibutuhkan backend atau service email eksternal.

## Lisensi

Proyek ini milik pribadi dan ditujukan untuk portofolio. Silakan gunakan sebagai referensi.
